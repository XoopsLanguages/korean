XOOPS 설치

최초 설치

서문:

웁스 은 오픈 소스입니다. PHP로 작성된 객체지향 웹 출판 시스템. 이상적인 도구입니다. 크고 작은 동적 커뮤니티 웹사이트, 회사 내 포털, 기업 포털, 웹로그 등을 개발합니다.

XOOPS는 다음 조건에 따라 출시됩니다. GNU 일반 공중 라이선스(GPL) 버전 2 이상이며 자유롭게 사용하고 수정할 수 있습니다. GPL 배포 조건을 준수하는 한 자유롭게 재배포할 수 있습니다.

요구사항

  • WWW 서버(아파치, NGINX, IIS 등)
  • PHP 8.2 이상, 8.4+ 권장
  • MySQL 5.7 .8 이상, MySQL 8.4.5+ 권장

설치하기 전에

  1. WWW 서버, PHP 및 데이터베이스 서버를 올바르게 설정하십시오.
  2. XOOPS 사이트용 데이터베이스를 준비하세요.
  3. 사용자 계정을 준비하고 해당 사용자에게 데이터베이스에 대한 액세스 권한을 부여합니다.
  4. 디렉토리와 파일을 쓰기 가능하게 만드세요: %s
  5. 보안을 고려하여 아래 두 디렉터리를 다른 곳으로 옮기는 것이 좋습니다. 문서 루트 폴더 이름을 변경합니다: %s
  6. 디렉터리를 만들고(아직 없는 경우) 쓰기 가능하도록 설정: %s
  7. 브라우저의 쿠키와 JavaScript를 켜십시오.

로컬로 설치

개발이나 테스트를 위해 로컬 환경을 실행하는 경우 이전 버전이 있는지 확인하세요. 요구 사항이 충족되었습니다. 이 작업이 완료되면, htdocs directory (from the XOOPS distribution file) to the root document path of your web environment. Once the files are copied there, you can start the install by pointing you browser to "http://yoursite.com". 그러면 설치 프로세스가 시작됩니다.

호스팅된 플랫폼에 설치

호스팅된 환경에서 실행 중인 경우 로컬로 또는 서버에서 XOOPS 파일의 압축을 풉니다. 셸(예: SSH) 액세스. 완료되면 모든 XOOPS 파일을 다음에서 이동하거나 복사하십시오. htdocs 디렉터리를 루트 웹 디렉터리로 복사합니다(공급업체는 일반적으로 이 위치에 지침을 제공합니다). 파일이 복사되면 브라우저를 가리켜 설치를 시작할 수 있습니다. "http://yoursite.com". 그러면 설치 프로세스가 시작됩니다.
