도움말: 배너

설명

배너는 페이지 상단에 표시되는 광고입니다. 이미지나 플래시 동영상일 수 있습니다. 기본 설치의 일부인 격렬하게 회전하는 XOOPS 배너. XOOPS에는 배너를 관리하고 광고 클라이언트를 위한 계정을 생성하는 시스템이 내장되어 있습니다. 시스템 모듈 -> 배너에 있습니다. XOOPS 사이트에는 여러 개의 배너가 있을 수 있습니다. 새 페이지가 로드될 때마다 표시 영역이 각 활성 배너를 차례로 순환합니다.

방문자에게 배너가 표시될 때마다 이는 배너의 일반적인 거래 통화인 하나의 '노출'로 계산됩니다. 클라이언트는 일반적으로 특정 노출 수에 대해 비용을 지불합니다. 즉, 광고가 특정 횟수만큼 표시되도록 하는 것입니다.

참고: 노출 수를 기준으로 배너를 판매하는 사업을 하고 있는 경우 수행해야 할 중요한 작업이 하나 있습니다. 시스템 모듈 -> 기본 설정 -> 일반 설정으로 이동하여 '귀하의 IP 주소' 필드(있는 경우)를 입력합니다. 이렇게 하면 귀하의 방문을 방지할 수 있습니다. 사이트가 노출수에 포함되지 않습니다. 이를 수행하지 않는 것은 다소 부정직한 것으로 간주될 수 있습니다(그러나 전화 접속 모뎀을 사용하는 관리자와 같이 많은 관리자가 영구 IP를 가지고 있지 않다는 점에 유의하십시오).
