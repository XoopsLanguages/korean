도움말: 템플릿

설명

XOOPS는 사이트의 실제 표시('피부" 또는 사용자 인터페이스) 및 뒤에서 실행되는 코드. 첫 번째 코드는 그래픽 테마를 기반으로 한 정교한 메커니즘에 의해 처리됩니다. 테마에는 기본 형식에 필수 HTML이 포함될 수 있습니다. 사이트의 시각적 인터페이스를 정의하는 템플릿과 해당 시각적 인터페이스를 보완하는 데 필요한 스타일 시트 및 이미지가 포함됩니다. 테마는 관리 인터페이스에서 전환할 수 있으므로 XOOPS 사이트의 전체 모양을 변경하는 것은 단지 선택하고 "수락"을 클릭합니다. XOOPS는 또한 사이트 관리자에게 사용자가 사용 가능한 테마 중에서 선택할 수 있는 기능을 제공합니다.

일반적으로 말하면, 테마 은 사이트의 높은 수준의 시각적 프레임워크입니다. 테마는 예를 들어 사이트의 일반적인 레이아웃을 정의합니다. 반면에 일반적으로 블록 내 콘텐츠의 구체적인 배포를 정의하지 않습니다. 이는 다음에서 처리됩니다. a라고 불리는 다른 실체 템플릿 세트. 템플릿 세트 은 XOOPS 웹사이트를 구성하는 모든 블록 내에서 콘텐츠 표시를 정의하는 HTML 템플릿의 집합입니다. 이에 대한 보다 명확한 은유를 원한다면 주제는 다음과 같다고 말할 수 있습니다. 템플릿 세트는 집의 건축가와 같고, 템플릿 세트는 실내 장식가와 같습니다. 첫 번째 사람은 벽을 설정하고 일반적인 배포를 정의하지만 두 번째 사람은 "드레싱” 저 벽이요.

활성 테마가 테마 파일, CSS 파일 및 일부 이미지만 포함하는 간단한 테마인 경우 XOOPS는 기본 템플릿 세트를 사용하여 블록 표시를 정의합니다. 그러나 일부 복잡한 테마는 자체 템플릿 세트를 포함할 만큼 정교합니다. 이 경우 해당 사이트는 관리자는 관리 인터페이스를 사용하여 테마와 템플릿 세트를 모두 설정해야 합니다.

테마는 어떤가요? 마법 달성됐나요? 즉, HTML 템플릿에 동적 콘텐츠를 어떻게 포함할 수 있습니까? 이는 거울과 연기가 아닌, 스마티 부르던 것의 기능을 만들어주는 것 변수 보간. 간단한 방법으로 표현하면, XOOPS 시스템은 모듈의 논리(데이터베이스 액세스, 변수 할당, 권한 관리...)를 유지하기 위해 PHP 파일을 사용하고, Smarty 변수가 삽입된 HTML 파일을 사용하여 관리한다고 말할 수 있습니다. 실제 시각적 인터페이스와 최종 사용자가 보는 페이지를 구성하는 HTML 내의 특정 위치에 값과 문자열을 삽입하는 Smarty 엔진이 있습니다. 전체적으로 이것이 의미하는 바를 쉽게 요약할 수 있습니다. 테마 시스템 덕분에 XOOPS를 사용하면 사이트 디자이너가 더 많은 것을 만들 수 있습니다. 내부에서 일어나는 일에 대해 크게 걱정하지 않고 흥미롭고 시각적으로 멋진 사이트입니다.

템플릿 세트 복제 및 다운로드

사용자 정의 템플릿 세트를 생성하려면 '클론’ 링크(새 세트에 이름을 지정하라는 메시지가 표시됩니다). 기본과 달리 다른 템플릿 세트는 자유롭게 편집할 수 있습니다. 사본을 저장할 수도 있습니다. '를 선택하여 디스크에 설정된 템플릿다운로드' 링크를 삭제하거나 '삭제’ 링크입니다. 때로는 추가 '생성' 링크는 아직 템플릿이 생성되지 않은 새 모듈 옆에 있습니다.

템플릿 편집

디렉토리 트리뷰를 탐색하면 사용 가능한 템플릿의 전체 목록을 볼 수 있습니다. 템플릿을 선택하면 XOOPS는 편집할 수 있는 편집기에서 해당 템플릿을 엽니다.

템플릿을 편집하는 동안 현재 테마에 대한 테마/테마/템플릿 디렉터리 아래에 최신 파일이 있는 경우 모듈 템플릿 .tpl 파일을 자동으로 업데이트하는 기본 설정을 활성화해야 합니다(시스템 모듈 -> 기본 설정 -> 일반 설정 -> 모듈 템플릿 .tpl 파일 업데이트). 테마/테마/템플릿 디렉토리에서? -> '예'). 사이트가 공개되면 이 기능을 꺼야 합니다.

실수로 템플릿을 망친 경우 '좋아요' 기본 템플릿 세트에서 복사합니다. 비표준 템플릿으로 작업하는 경우 수정을 시작하기 전에 복사본을 디스크에 저장하는 것이 좋습니다.
