-----도움말 내용 ----------

설명

프로필 모듈은 사용자 정의 사용자 프로필 필드를 관리하기 위한 것입니다.

설치/제거

특별한 조치가 필요하지 않습니다. 표준 설치 프로세스를 따르십시오. /profile 폴더를 ../modules 디렉토리에 추출하십시오. 관리 -> 시스템 모듈 -> 모듈을 통해 모듈을 설치합니다.

모듈 설치에 대한 자세한 지침은 XOOPS 운영 매뉴얼

작동 지침

이 모듈을 설정하려면 다음이 필요합니다.

  • 모듈에 대한 기본 설정('기본 설정' 참조)을 구성하고, 사용하려는 경우 선택적으로 프로필 블록('블록' 참조)을 구성합니다.
  • 기존 카테고리를 편집하거나 새 카테고리를 추가하세요.
  • 기존 필드를 편집하거나 새 필드를 추가합니다. 여기서는 어떤 필드가 어떤 범주에 표시되는지, 사용자 등록 중에 해당 필드가 표시되는지 여부를 지정할 수 있습니다.
  • 등록 단계의 순서를 정의합니다.
  • 그리고 마지막으로 개별 필드에 대한 권한을 설정할 수 있습니다(편집 가능한 필드, 검색 가능한 필드).

스팸방지 대책

스팸 등록을 최소화하려면 다음을 수행하십시오.

  • 관리의 보호기 모듈로 이동하여 기본 설정으로 이동한 후 하단의 이 옵션에서: "포럼 스팸을 중지하세요" www.stopforumspam.com 데이터베이스에 등록된 스패머에 대해 POST 데이터를 확인합니다.
    'IP 차단(제한 없음)'으로 설정하세요.

  • 모드가 "text"로 설정되어 있는지 확인하세요.

    $config = 배열(
    'disabled' => false, // CAPTCHA 비활성화
    'mode' => 'text', // 기본 모드, 'text', 'image', 'recaptcha'(api 키 필요)를 선택할 수 있습니다.
    'name' => 'xoopscaptcha', // 보안문자 이름
    'skipmember' => true, // 회원에 대한 CAPTCHA 확인 건너뛰기
    'maxattempts' => 10, // 각 세션의 최대 시도 횟수
    );

  • 프로필 모듈에서 관리자로 이동하고 다음 위치에 있는 기본 단계로 이동합니다.
    /modules/profile/admin/step.php?id=1
    "정지 후 저장"을 "아니요"로 설정합니다.


  • 프로필 환경설정에서 "두 번째 등록 단계 후 보안문자 사용" 옵션을 "예"(기본값)로 설정하세요.
