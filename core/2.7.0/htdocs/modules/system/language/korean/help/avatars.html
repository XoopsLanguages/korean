도움말: 아바타

설명

아바타는 사이트 주변의 다양한 콘텐츠 설정에 사용할 수 있는 작은 그래픽이나 그림입니다. 이는 약간의 "시각적 식별"을 추가하기 위해 사용자 이름 옆에 자주 사용됩니다. 일반적인 응용 프로그램은 포럼입니다.

사이트 관리자는 아바타 관리자를 사용하여 시스템 아바타와 사용자 정의 아바타를 추가, 편집 또는 삭제할 수 있습니다.

시스템 아바타

시스템 아바타는 사이트 관리자가 아바타 관리자 섹션에 업로드한 이미지입니다.

맞춤 아바타

맞춤 아바타는 사용자가 직접 업로드한 이미지입니다. 사용자가 아바타를 업로드할 수 있으려면 사이트 기본 설정의 사용자 정보 설정에서 올바른 옵션을 구성해야 합니다.

아바타 편집 및 삭제

사이트 관리자는 모든 시스템 아바타의 이름과 표시 순서를 편집할 수 있을 뿐만 아니라 그중 하나를 삭제할 수도 있습니다. 사이트 관리자가 사용자가 사용 중인 아바타를 삭제하면 해당 사용자는 아바타를 잃게 됩니다.
