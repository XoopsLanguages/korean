도움말: 모듈

설명

모듈은 XOOPS가 제공하는 인프라를 활용하여 웹마스터가 사용하기 쉽지 않은 웹 인터페이스를 사용하여 생성된 동적 또는 정적 콘텐츠를 사이트 사용자에게 제공할 수 있도록 하는 소프트웨어 구성입니다.

XOOPS의 강력한 기능 중 하나는 모듈을 관리하는 방식에 있습니다. 웹마스터는 특정 모듈(분명한 이유로 시스템 모듈 제외)을 쉽게 설치, 제거, 활성화 또는 비활성화할 수 있습니다. 모듈의 이름을 바꾸고 모듈의 순서를 결정하는 것도 가능합니다. 사이트 메뉴에서 최종 사용자에게 표시됩니다(전혀 표시되기를 원하는 경우). 왜냐하면 일반 사용자에게 보이지 않는 활성 모듈을 정의하여 숨겨진 기능을 제공할 수도 있기 때문입니다. 예를 들어, 모듈을 비활성화하여 메뉴에 표시되지 않도록 정의할 수 있습니다. 메뉴 열에서 아이콘을 확인하세요. 따라서 뉴스 모듈의 경우 선택한 사용자 그룹에게 비공개 메시지를 보내고 URL 필드에 다음과 같은 주소를 입력하여 해당 디렉토리에 액세스하도록 지시할 수 있습니다. http://www.yoursite.com/modules/news.

모듈의 순서를 변경하려면(메뉴에 반영됨) 모듈을 원하는 위치에 끌어서 놓기만 하면 됩니다.

모듈 설치에는 표시할 모듈과 페이지의 레이아웃에 대한 계획이 필요합니다. 다른 XOOPS 사이트를 검토하고 다양한 유형의 콘텐츠를 표시하는 데 어떤 모듈이 사용되는지 확인하는 것이 좋습니다. XOOPS 사이트를 열고 위에 마우스를 올리면 쉽게 수행할 수 있습니다. 메뉴 링크는 왼쪽 및 오른쪽 패널에 있습니다. 동시에 브라우저의 상태 표시줄에 표시된 URL을 살펴보세요. 다음과 같은 주소가 표시되어야 합니다. http://the_site.com/modules/news/.... 모든 모듈은 /modules/ 디렉터리에 저장되므로 다음 섹터는 주소(이 예에서는 'news')는 해당 메뉴 링크의 내용을 표시하는 모듈을 보여줍니다.

링크 페이지를 열면 모듈 사용 방법과 표시되는 콘텐츠 유형에 대한 예가 표시됩니다. 이와 같은 다른 사이트를 검토하면 레이아웃 및 디자인 기능에 대한 좋은 통찰력을 얻을 수도 있습니다.
